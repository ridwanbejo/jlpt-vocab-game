# JLPT Vocabulary Game

## A. Overview

Developed by Ridwanbejo, this game is made with Gemini, Phaser.js, HTML5, CSS, Javascript. 

The motivation behind this game is that I can't find any games or applications that offer Japanese typing practice with experience as Typeshark Deluxe. Japanese characters are consists of Hiragana (basic), Katakana (basic) and Kanji (advance). This game is built based on vocabulary for JLPT N5 till N1.

## B. Features & Requirements

- 8000++ Japanese words (mix of Kanji, Hiragana, Katakana)
- translation in English for each words
- romanization for each words
- JLPT level filter: N5, N4, N3, N2, N1, or All level
- Kana script filter: Hiragana only, Katakana only, Mix of both
- Random Words picker with minimum 10 words and max 200 words
- Adjustable game time from 1 minute to 5 mintues
- Adjustable level: easy, medium, hard
- in-game word and meaning minimap
- in-game syllables and romaji minimap

Requirements:

- Laptop or PC with Widescreen (not design for Mobile screen)
- [MacOS Japanese Hiragana and Katakana Keyboard Input](https://support.apple.com/id-id/guide/japanese-input-method/jpimf6ffb247/mac)
- [Windows OS Japanese Hiragana and Katakana Keyboard Input](https://learn.microsoft.com/en-us/globalization/input/japanese-ime)
- [Linux Japanese Hiragana and Katakana Keyboard Input](https://blog.timbrockley.co.uk/linux/japanese-input-method/)

Once you are ready with the Japanese Hiragana and Katakana Keyboard Input. You can play this game as many as you can.

Check the game [>> here <<](https://jlpt-typing-master.ridwanbejo.workers.dev/)
